Лабораторная работа 1

Задание

Вариант 21. Создать горизонтальное меню навигации, которое при ширине экрана менее 768px превращается в вертикальное меню.

Реализация

Разметка — семантический <header> с логотипом и блоком <nav>, внутри которого список <ul class="nav__list"> со ссылками. По умолчанию список пунктов меню выстроен в строку (display: flex; flex-direction: row). В media-запросе @media (max-width: 768px) направление flex-контейнера меняется на column, шапка сайта тоже становится колонкой, а каждая ссылка растягивается на всю ширину для удобства нажатия на мобильных устройствах. Добавлены состояния :hover и :focus-visible для пунктов меню. Inline styles не используются, все стили вынесены в styles.css.

Запуск

Открыть файл index.html в браузере через двойной клик. Дополнительная сборка не требуется.
